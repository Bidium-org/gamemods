# Tic-tac-toe

Three in a row against a bot. You play X, the bot answers with O in the same step. The bot plays well but makes a random move about one time in three.

## Play

| Key       | Action          |
| :-------- | :-------------- |
| `w a s d` | Move the cursor |
| `e`       | Place your mark |

The score is your win streak. A loss or a draw ends it; `r` after a win keeps it, `r` during a game ends it.

## Manual checks

Part of the manual protocol of [CONTRIBUTING.md](../../../CONTRIBUTING.md#manual-protocol): a win, a loss and a draw with `w a s d` and `e`.

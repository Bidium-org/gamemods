# Security

## Reporting a vulnerability

Do not open a public issue. Email **bidiumdev@gmail.com** with:

- what the issue is and what it lets someone do;
- steps to reproduce;
- the Claude Code build and surface (Desktop or terminal).

## Supported versions

Only the latest release gets fixes.

## Scope

The mod makes no network or model calls. It reads and writes one value per game (the best score) in the plugin store that Claude Code manages, and opens no file itself.
